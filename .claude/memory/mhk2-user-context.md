The user is the author of `mhk2_manager.jar` ("Moorhuhn Kart 2 - File Manager", Java/Swing, GitHub Markimk13/mhk2_manager) which backs up phantoms, championship results and highscores for Moorhuhn Kart 2 XXL. They keep two game copies ("FPS 60" and "FPS 200") with identical exe/data, play time trials seriously (many phantom backups), and the game texts are German.

The manager V1.0 (2020) hard-coded three engine classes (`Engine.ENGINE_50/100/150`). On 2026-11-22 the user had V1.1 made: it knows 200 ccm, 250 ccm and Tuning (details in [[mhk2-phantom-and-manager-internals]]). The user wants personal data out of their public repos (commit addresses, contact address, player names in screenshots), see [[mhk2-public-release]].

The patch was started on 2026-11-18 in the user's private repository (first commit "Add 200 ccm with Fable 5.2") and later moved into this public repository, see [[mhk2-public-release]].

See also [[mhk2-windowed-test-recipe]].
